# /wdp-clear — 清空总结文档

删除存储根目录下保存的文档。**不可逆的破坏性操作，删除前必须二次确认。**

## 存储根目录（所有 wdp 命令共用）

1. 若本技能目录存在兄弟目录 `wdp-sum`（即 `../wdp-sum/summaries/`），优先使用它；
2. 否则回退到 `~/.claude/skills/wdp-sum/summaries/`。

## 默认行为（快照 vs 档案）

- **快照**（`<时间戳>.md`）：默认删除对象。
- **profile**（`profile.md`）：默认**保留**，它是长期稳定信息。若用户明确要求连档案一起删，才删除。
- **latest.md**：指针文件，删除快照后一并清理。
- **`--keep N`**：每个项目**保留最新的 N 份**快照，只删更旧的（N=0 等同默认全删）。

## 执行步骤

### 1. 明确范围
先问清楚用户要清什么：
- 全部快照（默认）；
- 全部快照 + profile 档案（显式要求）；
- 仅某个项目（`/wdp-clear <项目路径>`）；
- 仅 profile（`/wdp-clear --profile`）；
- 保留最近 N 份：`/wdp-clear --keep N`（可叠加项目路径：`/wdp-clear <项目路径> --keep 3`）。

### 2. 计算删除清单（含保留策略）
- 用 Glob 列出目标范围内所有快照文件；
- 若带 `--keep N`：按项目分组，对每个项目**按文件名时间戳从新到旧排序**，前 N 份划入"保留"，其余划入"删除"；
- 向用户展示：**删除清单**（相对路径 + 生成时间）+ **保留清单**（N 份），并注明"保留最新 N 份"策略。
- 注意：`latest.md` 若指向的正是被删的快照，会一并列入清理；`profile.md` 默认不在删除清单内。

### 3. 二次确认（必须）
- 明确询问"确认删除这 N 份文档（保留 M 份）？此操作不可恢复。"
- **确认前绝不执行删除**；拒绝时报告"已取消，未删除任何文件"。

### 4. 删除
- 只删除清单中的文件，保留清单一律不动；
- 若删除后项目子目录为空，保留目录骨架；
- 删除后：若 `latest.md` 指向的文件已被删，将其指向保留清单中最新的一份；若无保留，删除 `latest.md`；
- 报告：删除了 N 份，保留了 M 份。

## 常见错误

| 错误 | 修正 |
|------|------|
| 不确认直接删 | 破坏性操作必须先列清单再二次确认 |
| 误删 profile.md | 默认保留档案，除非显式要求 |
| 误删 latest.md 但保留快照 | 指针与快照状态保持一致 |
| 删了存储目录外的文件 | 只允许操作存储根目录内 |
| `--keep N` 删了新快照 | 排序方向搞反会删掉最新的，务必从新到旧保留前 N |
| 删后 latest.md 悬空 | 指向已删文件时必须改指保留清单中最新的那一份 |
